# BloomCraft

Bosses, relics, pets, quests and skills as one Fabric mod, for singleplayer worlds and small worlds with friends
(Open to LAN). It's the mod version of the Additional Bosses, BloomPets and QuestBook server plugins.

Minecraft 26.3, Fabric Loader 0.19.5+, Fabric API. Java 25.

## Install

1. In the CurseForge app, make (or open) a **Fabric 26.3** profile and add **Fabric API** to it.
2. Download `BloomCraft.jar` from the latest successful **Build BloomCraft** run (Actions tab → the run → Artifacts).
3. In the profile, open the mods folder (⋯ → Open Folder → `mods`) and drop the jar in. To update, replace the jar.

`/version` isn't a thing in singleplayer, so the build number is shown in the mod list and in the log when the game
starts (`BloomCraft 1.0.0-b12+abc1234 loading`).
